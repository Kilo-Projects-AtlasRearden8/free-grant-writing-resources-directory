# Free Grant-Writing Resources Directory

A free, beginner-friendly directory of grant-writing resources: funder databases,
proposal templates, budget worksheets, and writing guides.

**Credit:** Asdale Dynamics, LLC
**Scope:** Official links only. Education only.
**License:** MIT (see LICENSE)

> Nothing in this directory is medical, legal, or financial advice. It is for
> educational purposes only.

---

## How to use

Each resource below links to its official website. All are free to access (some
offer optional paid upgrades). Search the live site at `index.html` to filter by
cause or resource type.

## Resource types

- **Funder database** — Searchable listings of grantmakers and funding opportunities.
- **Writing guide** — Guidance on how to write and submit grant proposals.
- **Proposal template** — Fill-in templates for grant and project proposals.
- **Budget worksheet** — Worksheets for planning project budgets.
